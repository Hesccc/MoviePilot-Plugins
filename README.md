# [🎬 MoviePilot-Plugins](https://github.com/Hesccc/MoviePilot-Plugins)

MoviePilot 第三方插件库，提供了一系列实用的插件来增强 MoviePilot 的功能。

> ⚠️ 注意：本插件库为个人维护，代码结构参考了其他开源项目。推荐优先使用[官方插件库](https://github.com/jxxghp/MoviePilot-Plugins)。

---

## 🛠️ 添加本插件市场

在 MoviePilot 后台 **「设定」 -> 「插件」 -> 「插件市场」** 中，添加以下仓库地址：

```
https://github.com/Hesccc/MoviePilot-Plugins
```

## [📦 插件列表](https://github.com/Hesccc/MoviePilot-Plugins/tree/main)

### 1. 📢 绿联NAS通知转发 (UgnasNotify)

* **版本**：v1.0.5
* **功能**：定时获取绿联 NAS 通知，通过外部消息转发插件转发至企业微信
* **标签**：消息通知
* **更新说明**：
    * `v1.0.5`: 添加 NAS 连通性检测判断。
    * `v1.0.4`: 修改插件判断 auth_info 文件是否存在逻辑。
    * `v1.0.3`: 优化插件界面和说明描述。
    * `v1.0.2`: 优化禁用插件后，历史定时任务继续执行问题。
    * `v1.0.1`: 优化定时任务配置。
    * `v1.0.0`: 接收外部应用自定义消息并推送。

### 2. 🧹 Void 冗余文件清理 (VoidCleaner)

* **版本**：v1.2.4
* **功能**：精准扫描并清理 PT/BT 下载目录中未在任何客户端做种、未硬链接的残留孤儿文件（支持本地及自定义多节点 SSH 远程下载器）
* **标签**：文件管理
* **核心特性**：
    * **左侧导航专属交互界面**：内置 `get_page()` 路由，在 MP 左侧边栏新增 **「Void 清理」** 独立入口，支持实时展示待清理文件、空间释放统计、在线一键扫描与批量清理。
    * **彻底告别路径映射**：自动继承 MoviePilot 系统中已配置的 `DOWNLOAD_PATH`（下载目录），无需手动配置容器转换路径。
    * **彻底免配下载器**：自动读取 MoviePilot 现有的 qBittorrent / Transmission 客户端连接池，开箱即用。
    * **单文件展开 + Inode 硬链接穿透保护**：展开种子内部每个真实文件，精准定位解压多余垃圾；通过 `(st_dev, st_ino)` 校验，绝不误杀被转移到影视库的同源文件！
    * **多节点远程 SSH 下载器支持**：支持自定义配置远程 SSH 下载器节点，提供连通性实时测试、远程文件大小/Inode流式核验与远程安全清理。
    * **原生复用 MP 通知中心**：巡检完成自动调用 MP 原生通知网关，企业微信、Telegram、网页端全渠道排版推送。
* **更新说明**：
    * `v1.2.4`: 重大升级多维做种比对引擎：彻底解决群晖/分类子目录（如 Manually/）、下载中临时文件（.!qB）被误报为未做种文件的路径不对称 Bug。
    * `v1.2.3`: 深度对接 MP 系统目录设置：自动识别并继承【设定->目录】中配置的全部下载目录，支持本地多目录并发检索。
    * `v1.2.2`: 修复定时服务注册 CronTrigger 关键字异常，修复日志查看 404 问题。
    * `v1.2.1`: 优化多节点远程下载器及路径匹配，支持企业微信/Telegram等全渠道原生通知推送。
    * `v1.1.0`: 升级版本：支持多节点自定义远程 SSH 下载器配置、连通性实时测试、远程文件大小/Inode流式核验与远程安全清理。
    * `v1.0.0`: 首发版本：集成单文件级展开检索、Inode 硬链接穿透保护、MP 原生多渠道推送与可视化操作。
